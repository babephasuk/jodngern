# จดเงินของเบ๊บ (หน้าแอป)

หน้าแอปจดรายรับ-รายจ่ายแบบติดตั้งบนมือถือได้ (PWA) โฮสต์บน GitHub Pages

- repo นี้มีเฉพาะหน้าตาแอป **ไม่มีข้อมูลการเงิน ไม่มีลิงก์ API และไม่มีกุญแจ**
- ข้อมูลทั้งหมดอยู่ใน Google Sheet ส่วนตัว เรียกผ่าน Apps Script ที่ต้องใช้กุญแจลับ
- ลิงก์ API และกุญแจตั้งในแต่ละเครื่องตอนเปิดแอปครั้งแรก เก็บในเครื่องนั้นเท่านั้น
- ล็อกแอปด้วยลายนิ้วมือ / Face ID หรือ PIN 6 หลัก
- 2.2.0: กดบันทึกแล้วขึ้นทันที ส่งเข้าชีตเบื้องหลัง รายการที่ยังส่งไม่สำเร็จพักไว้ในเครื่องจนส่งได้ (เครื่องจำรายชื่อหมวดไว้ด้วย ไม่มีจำนวนเงิน)
- 3.0.0: แท็บภาพรวม (สลับรอบเงินเดือน/เดือนปฏิทิน การ์ดสรุปเทียบช่วงก่อน รายจ่ายตามหมวด กราฟใช้จ่ายสะสม กราฟย้อนหลัง 12 ช่วง) และแก้แม่แบบวันเงินเดือนจากมือถือ (ต้องใช้ Code.gs 3.0.0)
- 4.0.0: แท็บงบดุล (ความมั่งคั่งสุทธิ อัปเดตยอดประจำเดือน ประวัติรายรายการ กราฟย้อนหลัง 12 เดือน) คะแนนสุขภาพการเงิน 4 กลุ่ม ส่งออก CSV และสำรองชีตไว้ใน Drive (ต้องใช้ Code.gs 4.0.0 และรัน setupBackup ใน Apps Script หนึ่งครั้ง) ยอดงบดุลไม่ถูกเก็บในเครื่อง

ไฟล์: `index.html` (ตัวแอป) · `sw.js` (แคชหน้าแอปให้เปิดเร็ว) · `manifest.webmanifest` + `icon-*.png` (ติดตั้งเป็นแอป)

ตอนแก้ไฟล์แอป ให้เปลี่ยนเลขใน `sw.js` บรรทัด `var CACHE = 'jodngern-…'` ด้วย มือถือจะได้โหลดเวอร์ชันใหม่
